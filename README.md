# Apartment Wiki Korea

대한민국 아파트 실거래가와 단지 정보를 조회할 수 있는 웹 서비스입니다.

## 프로젝트 목표

- 국토교통부 실거래가 데이터 수집
- 전국 아파트 검색
- 실거래가 조회 및 그래프
- 단지 정보(Wiki) 관리

## 기술 스택

- Frontend: Next.js
- Backend: Next.js API
- Database: Supabase (PostgreSQL)
- Data Collector: Python
- Deployment: Vercel
